# Manual Test Plan

**System under test:** SauceDemo (https://www.saucedemo.com/)  
**Objective:** Validate critical e-commerce flows and document observed behavior.  
**Test type:** Manual functional testing, smoke checks, positive and negative cases.  
**In scope:** Login/logout, inventory, cart, checkout.  
**Out of scope:** Performance, penetration testing, payment processing, mobile-app compatibility.

- Test credentials are available from the demo site.
- Test case tracker is prepared.

## Exit criteria
- All planned cases have Pass, Fail, or Blocked status.
- Failed cases have reproducible notes and defect reports where appropriate.
- Test summary is completed with unresolved risks.

## Defect management
Use `BUG-TEMPLATE.md`. Record expected vs actual behavior, reproducible steps, environment, severity, and evidence. Distinguish intended demo behavior from actual defects.
